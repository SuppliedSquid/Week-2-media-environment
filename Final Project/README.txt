FINAL PROJECT GAME PITCH

- reaction time and aim challenge or clicks per second test

- For the aim game click the button within the time limit to increase your score otherwise you lose. For the click rate test click the button to increase score.

- For the aim game the button that the player needs to click is in a new random position each time it is clicked. As the game progresses the timer shortens and the button gets smaller. For the click rate game the player clicks as much as they can within 5 seconds.

- For the aim game the player loses when they do not click the button within the timer shown on screen. There is no win condition, arcade style. Highscore. For the click rate test the player loses when they do not get a new high score.
